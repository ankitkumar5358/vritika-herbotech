# Architecture rules

- Preserve five TanStack Start file-based pages in a shared Navbar/Footer shell to retain routing and server rendering.
- Reuse site-data for company and product facts to avoid inconsistent claims.
- Keep Contact informational with mailto/tel links; there is no message-delivery service.
- Keep site-images as the single local image catalogue for easy replacement.
- Use native dialogs and the shared Button for consistent accessible interactions.
